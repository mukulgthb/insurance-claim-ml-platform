# Synthetic Insurance Claims Model-Serving Platform

A Phase 0 educational project demonstrating synthetic model training,
artifact persistence, and local REST inference.

## Purpose and Safety

The model estimates whether a synthetic insurance claim should be
routed for manual review. It is not a fraud detector, underwriting
system, or production insurance decision tool.

Only locally generated synthetic data is used. No employer code,
configurations, customer records, model artifacts, or proprietary
architecture diagrams are included.

The API is unauthenticated and must remain bound to localhost.

## Tested Environment

- Windows with Git Bash
- Python 3.14.5
- Resolved package versions: requirements-lock.txt

Other operating systems and Python versions have not been validated.

## Setup — Windows Git Bash

From the repository root:

```bash
python -m venv .venv
source .venv/Scripts/activate

python -m pip install --only-binary=:all: -r requirements-lock.txt
python -m pip check
```

## Train

```bash
python -m training.train
```

Training generates:

- artifacts/model.joblib
- artifacts/metadata.json

The script creates 2,000 synthetic examples and splits them into
1,600 training rows and 400 held-out test rows.

The artifact contains a fitted StandardScaler and LogisticRegression
Pipeline, plus metadata.

Recorded synthetic evaluation:

- Accuracy: 0.80
- ROC AUC: approximately 0.8258

These results do not establish usefulness on real insurance data.

## Run the API

Train first, then run:

```bash
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

The application loads the trusted model artifact during startup.
It does not train or reload the artifact on each request.

If the artifact is missing, startup fails. Run training to create it.

## Interactive Documentation

Open http://127.0.0.1:8000/docs while the server is running.

## Example Requests

Run these from another Git Bash terminal.

### Health

```bash
curl -i http://127.0.0.1:8000/health
```

Expected: HTTP 200 with loaded-model status and version.

### Valid Prediction

```bash
curl -i \
  -X POST http://127.0.0.1:8000/predict \
  -H 'Content-Type: application/json' \
  -d '{
    "claim_amount": 25000,
    "policy_tenure_days": 400,
    "previous_claims": 1,
    "incident_delay_days": 3
  }'
```

Expected: HTTP 200.

Recorded result for this input:

```json
{
  "model_version": "synthetic-claims-v1",
  "requires_manual_review": false,
  "review_probability": 0.2249527593193222
}
```

### Invalid Prediction

```bash
curl -i \
  -X POST http://127.0.0.1:8000/predict \
  -H 'Content-Type: application/json' \
  -d '{
    "claim_amount": -500,
    "policy_tenure_days": 400,
    "previous_claims": 1,
    "incident_delay_days": 3
  }'
```

Expected: HTTP 422 with a validation error for claim_amount.

## Tests

Generate the artifact first, then run:

```bash
python -m pytest -v tests/test_api.py
```

Recorded result: 12 passed, 1 dependency deprecation warning.

Tests cover health, valid and invalid input, agreement with direct
inference, key ordering, model reuse, and latency headers.

## Limitations

- Synthetic data only; no real-world model validation.
- No authentication or remote deployment.
- No production availability guarantee or monitoring platform.
- Model version is a descriptive label, not an immutable registry.
- Retraining overwrites the local artifact.
- Some accepted API ranges extend beyond the training ranges.
- Request timing is server-side, not network round-trip latency.
- A Starlette TestClient deprecation warning was observed.

## Artifact Security

Load only the artifact generated by the trusted local training script.
Do not load untrusted joblib artifacts.

Use the recorded dependency environment for training and serving.
Generated model artifacts are intentionally excluded from Git.
